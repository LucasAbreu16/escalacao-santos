# ⚽ Escalação Copa do Mundo 2026

Sistema web para criação e gerenciamento de escalações de futebol das principais seleções da Copa do Mundo 2026, permitindo que usuários montem seus times ideais, organizem jogadores por posição e salvem suas formações favoritas.

## 📋 Sobre o Projeto

A aplicação oferece recursos para:
- Cadastro e autenticação de usuários
- Gerenciamento de jogadores
- Criação de escalações
- Definição de formações táticas
- Armazenamento das escalações no banco de dados
- Visualização do time em campo

## 🚀 Tecnologias Utilizadas

### Backend
- Java
- Spring Boot
- Thymeleaf

### Frontend
- Javascript
- HTML5
- CSS3

### Banco de Dados
- PostgreSQL
